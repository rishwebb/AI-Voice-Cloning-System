# 🎙️ Vocalis: Few-Shot Neural Speech Synthesis & AI Voice Cloner

[![Python](https://img.shields.io/badge/Python-3.9%2B-blue.svg)](https://python.org/)
[![PyTorch](https://img.shields.io/badge/Framework-PyTorch%20%2F%20Deep%20Learning-red.svg)](https://pytorch.org/)
[![Audio](https://img.shields.io/badge/Domain-Speech%20Synthesis-green.svg)](https://github.com/rishwebb)

**Vocalis** is an AI-powered voice synthesis pipeline that clones vocal timbre and prosody from short reference audio recordings, generating natural speech waveforms from text prompts.
